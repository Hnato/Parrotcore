Chapter 1

Dashboard Overview & 3-Panel Layout

The main workspace is engineered for clarity, low resource consumption, and instant feedback. It is divided into three specialized panels:

  • Panel 1 Engine Controls (Top-Left, Compact): Houses up to five color-coded action buttons that adapt dynamically to the engine's state:
    • Start Engine (Green) / Stop Engine (Red): Starts or stops the HTTP web server immediately.
    • Restart (Orange): Appears while the server is running to perform a clean hot-restart.
    • Configure Database (Purple) / Restart DB (Amber): Opens Database Settings if unconfigured, or restarts the active database connection pool.
    • Open Website (Blue): Launches your default system browser pointing to either http://localhost:PORT or your active LAN IP address.
    • Project Inspector (Teal): Audits your website folder for missing entry files, viewport tags, PHP readiness, and optional database integration.
  • Panel 2 Live Resources Monitor (Bottom-Left): Displays real-time, instantaneous metrics sampled every second without disk overhead:
    • CPU Usage (%): Current processor load of the engine right now.
    • Memory (RAM): Current working set memory in megabytes (MB).
    • Network (Live): Instantaneous transfer rate (B/s, KB/s, MB/s) and requests per second (req/s). Drops back to 0 B/s • 0 req/s immediately when idle.
    • Active Cache: Current in-memory cache allocation held in RAM.
  • Panel 3 Live Console (Right Side, Full Height): Displays the startup banner and real-time logs for HTTP requests, database connections, PHP warnings, and live file modifications.

Chapter 2

Hosting Your Website & Custom Folders

By default, the engine serves files from the Web Site folder located next to the executable. However, you can select any directory on your computer:

  1. Option A: Default Folder: Copy your index.html, index.php, CSS stylesheets, JavaScript bundles, and images into the Web Site directory.
  2. Option B: Any Folder on Disk: Open Settings → Website, click Browse... next to Website Root Folder, and choose any project folder on your PC.
  3. Verify with Project Inspector: Click Project Inspector on the dashboard to view an in-app modal audit of your entry document and assets.
Automatic Favicon Support: Every generated starter page includes Parrotcore.ico as its favicon out of the box.

Chapter 4

Network Broadcasting (Localhost vs. 0.0.0.0) & Diagnostics

Under Settings → Network, control how your website is broadcast across your machine and local network:

  • Both Localhost & 0.0.0.0 (Recommended): Accessible via http://localhost:5009 on your PC and via your LAN IP address (e.g., http://192.168.1.25:5009) for phones, tablets, and other PCs on your Wi-Fi/LAN.
  • Localhost only (127.0.0.1): Restricts access strictly to your local machine.
  • Network Broadcast (0.0.0.0): Binds to all network interfaces and opens your LAN IP directly when clicking Open Website.

Chapter 5

Built-In Serverless SQLite Database & REST API Bridge

When Built-in Local SQLite Engine is active in Settings → Database, the engine manages a zero-configuration SQLite database at Engine/Data/parrotcore.db. When Expose '/api/db' bridge endpoint is enabled, your frontend JavaScript can store and query data directly:

:sqlite-rest-bridge.js <=> JavaScript (ES6+)
// 1. Save a JSON object into the built-in Key-Value store await fetch('/api/db/kv/users/profile_1', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Alex', role: 'Admin', active: true }) }); // 2. Read the item back const res = await fetch('/api/db/kv/users/profile_1'); const item = await res.json(); console.log(JSON.parse(item.json_data)); // 3. Execute a custom SQL query on SQLite const sqlRes = await fetch('/api/db/query', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ sql: 'SELECT collection, item_key, updated_at FROM key_value_store LIMIT 10' }) }); const data = await sqlRes.json(); console.log(data.rows);
Chapter 6

Local MariaDB / XAMPP & External Cloud Databases

The Database tab dynamically adapts its input fields based on your selected deployment mode and engine:

  • Built-in Local SQLite Engine: Shows only the SQLite file path and a Browse... button.
  • Local MariaDB / XAMPP Instance: Reveals the mysqld.exe path picker, Host/Port/Database/User/Password fields, and the Launch Local MariaDB / XAMPP button.
  • External Database Server / Cloud Cluster: Supports MariaDB, MySQL, PostgreSQL (port 5432), Microsoft SQL Server (port 1433), Microsoft Azure SQL (1433), and MongoDB (port 27017).

Chapter 7

PHP Scripting & Backend Integration (.php)

With Enable PHP Script Interpreter (.php support) enabled in Settings → Website, the engine executes .php files automatically and injects your active database credentials as environment variables:

index.php <=> PHP 8+ PDO Database Connection
<?php // Pre-injected environment variables from active Database Settings $provider = getenv('DB_PROVIDER'); if ($provider === 'SQLite') { $pdo = new PDO('sqlite:' . getenv('DB_SQLITE_PATH')); } else { $dsn = sprintf( 'mysql:host=%s;port=%s;dbname=%s;charset=utf8mb4', getenv('DB_HOST'), getenv('DB_PORT'), getenv('DB_NAME') ); $pdo = new PDO($dsn, getenv('DB_USER'), getenv('DB_PASS')); } echo 'Connected to database via ' . htmlspecialchars($provider); ?>

Chapter 8

Auto-Save Rules, Portability & Version Upgrades

Why Settings Auto-Save When the Server is Stopped: To guarantee stability and prevent mid-request port or database conflicts, settings are saved immediately whenever the server is stopped.
  • Full Windows 10 & Windows 11 Portability: All paths inside the application folder are stored as portable relative paths (Web Site, Engine/Data/parrotcore.db), so the entire application works seamlessly on any PC.
  • Safe Upgrades & Inno Setup Preservation: When installing a newer release from GitHub Releases, your settings in Engine/Data/parrotcore.config.json are preserved automatically.
